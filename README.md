# Sales Performance & Business Insights Dashboard

## Overview
An end-to-end sales analytics project using SQL and Power BI to analyze revenue, profitability, product performance, regional trends, and discount impact.

## Tools & Technologies
- **SQL:** PostgreSQL
- **Business Intelligence:** Microsoft Power BI
- **Data Modeling:** DAX measures
- **Visualization:** Interactive charts, KPI cards, and slicers

## Key Metrics
- Total Sales: 2.30M
- Total Profit: 286.40K
- Total Orders: 5,009
- Profit Margin: 12.47%

## Analysis
- Overall sales and profitability
- Monthly sales trends
- Sales by product category
- Profit by region
- Top 10 products by profit
- Profitability across discount levels

## Dashboard Features
- Interactive Year, Category, and Region slicers
- KPI cards for key business metrics
- Monthly trend and comparative analysis charts
- Key business insights and recommendations

## Repository Structure
- `sql/` — SQL analysis queries
- `screenshots/` — Dashboard and insights screenshots
- `sales_analysis.pbix` — Power BI report, if included

## Key Findings
- Technology generated the highest sales among the three categories.
- The West region recorded the highest total profit.
- Several higher discount levels were associated with negative profit.

## How to Use
1. Run the SQL scripts against the sales dataset in PostgreSQL.
2. Connect Power BI to the prepared data source.
3. Open the `.pbix` file to explore the report, if included.
